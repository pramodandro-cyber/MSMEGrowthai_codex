# MSMEGrowth AI

India’s AI-Powered Funding & Subsidy Intelligence Platform for MSMEs.

## Monorepo Structure

- `apps/web` - Next.js 14 frontend (TypeScript, Tailwind, shadcn-ready)
- `apps/api` - Express.js backend (TypeScript, Prisma, PostgreSQL)

## Quick Start

```bash
npm install
npm run dev
```

### Services

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8080`

See `docs/deployment.md` for production deployment instructions.
